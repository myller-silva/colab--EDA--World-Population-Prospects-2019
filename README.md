# EDA - World Population Prospects 2019

Este repositório contém um notebook Jupyter desenvolvido no Google Colab com o objetivo de realizar uma análise exploratória (EDA) sobre os dados do relatório **World Population Prospects 2019**, publicado pela ONU.

## Objetivo

Explorar e visualizar informações demográficas relacionadas ao crescimento populacional mundial, com foco em tendências por país e região ao longo do tempo.
